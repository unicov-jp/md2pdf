Google Cloud Console で「OAuth クライアントID（ウェブ アプリケーション）」を作り、承認済みの JavaScript 生成元にこのページの URL（例: https://unicov-jp.github.io）を登録します。APIキーは Google Picker API 用です。Google Drive API と Google Picker API を有効にしてください。権限は上の「権限」で選びます（チームで同じフォルダを使うなら drive）。index.html と同じ場所に md2pdf-config.json を置くと、チーム全員が同じ設定で始められます（この画面で保存した値が優先）。設定はこのブラウザにだけ保存され、アクセストークンは保存しません。file:// で開いたページでは Google にログインできません。
